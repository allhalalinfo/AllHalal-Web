2. Нажми **"Add New"**
3. Заполни:
   - **Name:** `NEXT_PUBLIC_API_URL`
   - **Value:** `https://api.allhalal.info`

4. Нажми **"Save"**

**Готово!** Vercel будет знать где искать API.

### Шаг 2: Передать задание Cursor агенту на Hetzner

Скопируй это сообщение и отправь своему **Cursor агенту**, который подключен к Hetzner серверу:


- Протестирует всё и напишет отчет

**Времени:** ~15-20 минут (автоматически)

## 🎉 ЧТО ПОЛУЧИШЬ В ИТОГЕ

### Архитектура (бесплатная и быстрая):

```
┌─────────────────────────────────────────────┐
│ Hetzner Server (твой сервер, $5/мес)        │
│                                             │
│  ┌──────────────┐    ┌────────────────┐    │
│  │ Redis Docker │◄───│ Python Cron    │    │
│  │ (localhost)  │    │ (30 min)       │    │
│  └──────┬───────┘    └────────────────┘    │
│         │                                   │
│  ┌──────▼──────────────────────────┐       │
│  │ FastAPI Endpoint                │       │
│  │ /api/v1/news/cached             │       │
│  └────────┬────────────────────────┘       │
│           │                                 │
└───────────┼─────────────────────────────────┘
            │ HTTPS
            ▼
┌───────────────────────────────┐
│ Vercel (Next.js)              │
│ ISR cache: 30 min             │
│ Fallback: direct RSS          │
└───────────────────────────────┘
```

### Преимущества:

- 💰 **Бесплатно**: используем только твой Hetzner
- ⚡ **Быстро**: Redis на localhost (1-5ms), FastAPI (10-20ms)
- 🔒 **Безопасно**: Redis закрыт, только HTTPS API
- 🛡️ **Надежно**: если Hetzner недоступен → fallback на RSS
- 📊 **Масштабируемо**: Redis хватит на миллионы запросов

### Производительность (реальная):

- **Homepage load:** 50-100ms (вместо 8-15 сек)
- **News page load:** 100-200ms (вместо 12-20 сек)
- **Cache hit rate:** ~95% (ISR в Next.js + Redis в Hetzner)
- **Hetzner RAM:** ~50 MB для Redis с новостями

## ❓ FAQ

**Q: Что если Hetzner упадет?**
A: Next.js автоматически переключится на fallback (прямой RSS парсинг). Сайт продолжит работать.

**Q: Нужны ли API ключи?**
A: Нет! Всё работает без внешних сервисов.

**Q: Сколько стоит в месяц?**
A: $0 дополнительных расходов. Используем только твой Hetzner ($5/мес, который уже оплачен).

**Q: Как проверить что всё работает?**
A: После деплоя открой:
- Homepage: https://allhalal.info/en (должны быть новости)
- API test: https://api.allhalal.info/api/v1/news/health (должен ответить `{"status": "healthy"}`)

**Q: Как посмотреть логи?**
A: SSH на Hetzner, выполни:
```bash
tail -f /var/log/allhalal-news.log
```
