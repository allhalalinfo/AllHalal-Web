ШАГИ НА ВАШЕМ КОМПЬЮТЕРЕ:
──────────────────────────────────────────────────────────────────────

1️⃣  Push изменений в GitHub:

    git push origin main


ШАГИ НА СЕРВЕРЕ HETZNER (49.12.186.18):
──────────────────────────────────────────────────────────────────────

2️⃣  Подключитесь к серверу:

    ssh allhalal@49.12.186.18


3️⃣  Создайте SSH ключ для GitHub:

    ssh-keygen -t ed25519 -C "github-deploy" -f ~/.ssh/github_allhalal
    cat ~/.ssh/github_allhalal.pub

    ⚠️  СКОПИРУЙТЕ ВЕСЬ ВЫВОД (начинается с "ssh-ed25519...")


4️⃣  Настройте SSH config:

    nano ~/.ssh/config

    Вставьте:
    ┌─────────────────────────────────────────┐
    │ Host github.com                         │
    │   HostName github.com                   │
    │   User git                              │
    │   IdentityFile ~/.ssh/github_allhalal   │
    │   IdentitiesOnly yes                    │
    └─────────────────────────────────────────┘

    Сохраните: Ctrl+O, Enter, Ctrl+X

    Установите права:
    chmod 600 ~/.ssh/config
    chmod 600 ~/.ssh/github_allhalal


5️⃣  Первый деплой:

    cd /home/allhalal/Allhalal-Web
    git clone git@github.com:allhalalinfo/AllHalal-Web.git .
    cp .env.example .env
    nano .env  # Настройте NEXT_PUBLIC_API_URL=https://api.allhalal.info
    npm ci --only=production
    npm run build
    pm2 start ecosystem.config.js
    pm2 save


ШАГИ В GITHUB:
──────────────────────────────────────────────────────────────────────

6️⃣  Добавьте SSH ключ в GitHub:

    Откройте: https://github.com/allhalalinfo/AllHalal-Web/settings/keys
    
    Нажмите "Add deploy key"
    
    Title: Hetzner Production Server
    Key: <вставьте скопированный ключ из шага 3>
    ✅ Allow write access
    
    Нажмите "Add key"


ПРОВЕРКА:
──────────────────────────────────────────────────────────────────────

7️⃣  Тест на сервере:

    ssh -T git@github.com
    # Должно вывести: "Hi allhalalinfo! You've successfully authenticated..."

    curl http://localhost:3000/api/health
    # Должно вывести: {"status":"healthy",...}

    pm2 status
    # Должно показать: allhalal-web | online


8️⃣  Тест автодеплоя:

    # На вашем компьютере:
    git push origin main
    
    # Проверьте GitHub Actions:
    https://github.com/allhalalinfo/AllHalal-Web/actions
